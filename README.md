# NEURO•CHIP LAB 3 — сүйреп құрастыру нұсқасы, 3-сынып, I тоқсан

Қазақ тіліндегі авторлық виртуалды зертхана. Ақшыл интерфейс, компьютердің көрнекі моделі, қозғалып тұратын робот белгішесі, зерттеу, диагностика, құрастыру, тест, миссия, мұғалім панелі және **әр бөлімдегі орындау алгоритмі** бар.

## Windows .exe алу
1. Осы папка ішіндегі файлдар мен `.github/workflows/windows.yml` файлын GitHub репозиторийіне құрылымын сақтап жүктеңіз.
2. Actions → Build NEUROCHIP Windows → Run workflow (немесе main-ға push).
3. Жасыл Success шыққан соң, run бетіндегі Artifacts → NEUROCHIP-LAB3-Windows файлын жүктеңіз.
4. ZIP-ті ашып, `NEUROCHIP-LAB3.exe` файлын іске қосыңыз. Python орнату қажет емес.

## Бастапқы кодты іске қосу (әзірлеушілерге)
`pip install -r requirements.txt`, содан соң `python app.py`.

## Ескертулер
- «NEURO» — ережелер бойынша кері байланыс беретін алгоритм; **нақты нейрожелі емес**.
- Компьютер моделі — сурет негізіндегі интерактивті визуализация, **толық 3D емес**.
- Дыбыстау Windows-тың System.Speech дауысына тәуелді; қазақ тілі орнатылмаса, дұрыс оқылмауы мүмкін.
- Құрастыру бөлімінде 5 бөлшек тышқанмен сүйреп апарылады: дұрыс ұяшық жасыл, қате ұяшық қызыл жыпылықтайды. «Тексеру», «Іске қосу», «Қайта бастау» батырмалары жұмыс істейді. Бұл — 2D схемалық симуляция, толық 3D емес.
- Оқушы нәтижелері жергілікті `%LOCALAPPDATA%/NeuroChipLab3/results.json` файлында сақталады.
- Зертхананың барлық батырмаларын Windows-та орнатқан соң тексеріңіз. Бұл ортада Windows GUI-ін толық тексеру мүмкін емес.
